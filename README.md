# SoloStudio Skills

### AI 自媒體一人公司技能庫

> 一個人，也能營運一間內容公司。  
> *Build a one-person media company with AI.*

SoloStudio Skills 是一份由社群共同維護的資源清單，聚焦自媒體創作者如何用 Agent Skills、AI 工具和可重現的工作流程，完成從選題到經營的內容工作。

本專案以繁體中文為主，歡迎補充英文及其他語言資源。這是一份經過編輯的目錄，不是工具背書；工具的價格、功能和授權可能改變，使用前請查看原始專案。

## 收錄原則

- 收錄與自媒體創作或一人內容事業有明確關聯的 Skills、工具、教學、範本或案例。
- 本清單的初始候選項目在 **2026-10-10** 查核時均超過 1,000 GitHub Stars。Stars 是變動中的人氣指標，不代表品質、活躍度或適用性；後續新項目不設 Stars 門檻，但必須符合主題並提供足夠資訊。
- 優先收錄能說明實際任務、輸入與輸出、限制及驗證方式的內容。
- 標明項目類型、支援平台、費用或帳號需求、授權，以及最後查核日期（已知時）。
- 保留原作者與原始 Repo 連結；第三方專案的授權仍由各自作者決定。本清單不複製第三方程式碼、提示詞或文件。
- 不收錄以未經同意抓取、冒用他人身分、垃圾訊息或規避平台規範為核心的流程。

## 一人媒體公司的工作流程

1. **定位與選題**：受眾研究、內容支柱、痛點整理、選題評分和內容日曆。
2. **腳本與文案**：標題與開場、長短影音腳本、品牌語氣、來源查核。
3. **製作與後製**：分鏡、拍攝清單、配音、字幕、縮圖和圖文素材。
4. **再製與發布**：將一份核心內容改寫成各平台適用的版本，人工確認後再發布。
5. **受眾與社群**：留言分類、回覆草稿、社群規範和互動回顧。
6. **營運與營收**：電子報、贊助合作、數位產品、成效分析和內容實驗。

後續可為每個流程增加可重現的範例：任務、輸入、步驟、輸出、人工檢查點、費用、授權與測試日期。

## 如何貢獻

歡迎提交新資源、繁體中文翻譯、過期資訊修正，以及你親自試過的創作工作流程。請閱讀 [CONTRIBUTING.md](CONTRIBUTING.md) 後開 Pull Request。

優先貢獻方向：

- 補上可重現的「選題到腳本」或「長片到短影音」工作流程。
- 實測 Agent Skill，說明適用情境、輸入與輸出，並提供人工修訂要點。
- 更新價格、平台支援、依賴、授權或停止維護狀態，附上來源。
- 翻譯內容並連回原文，確認有權分享翻譯或摘要。
- 比較不同工具完成同一項創作工作的效果與限制。

單純新增連結也歡迎，但請說明它解決什麼創作者任務，以及為什麼值得收錄。
