# SoloStudio Skills

### AI 自媒體一人公司技能庫

> 一個人，也能營運一間內容公司。  
> *Build a one-person media company with AI.*

SoloStudio 是給自媒體創作者的開放工作室：提供可直接閱讀與試跑的 Agent Skills、可重現的內容工作流程，以及經過篩選的工具目錄。

**首頁直接列出全部 56 個 Skill 檔案**：3 個原創 Skill，加上 53 個依授權與用途收錄的上游 Skill。按工作階段瀏覽，點 Skill 名稱即可開啟完整 `SKILL.md`；不是只有連到外部資源的書籤清單。

### 使用前先看相容性

- `marketingskills` 的 42 個 Skill 保留上游檔案與 MIT 授權，檔案可直接閱讀；部分工作流偏向網站、產品或付費成長，按需要選用。
- OpenMontage 影音 Skills 中，[Speech to Text](skills/third-party/openmontage/skills/speech-to-text/SKILL.md) 與 [Sound Effects](skills/third-party/openmontage/skills/sound-effects/SKILL.md) 在上游 frontmatter 標示 MIT；其餘採上游 AGPL-3.0。完整授權與來源版本見[第三方收錄紀錄](THIRD_PARTY_SKILLS.md)。
- 部分影音 Skill 要求 HeyGen、ElevenLabs、fal.ai、Kling 或 Gemini API 與金鑰；`FFmpeg`、`Video Edit`、`Video Understand` 可在本機工具安裝完成後使用。API 服務可能收費，Skills 本身不會提供帳號或金鑰。
- 上游內容原樣保存。部分項目會呼叫 OpenMontage 專用工具或提到其內部流程；目錄標示了限制，跨 Agent 相容性尚未逐項實測。使用前請閱讀對應的 `SKILL.md` 與參考檔案。

## 這個 Repo 歡迎什麼樣的 PR？

單純加連結可以幫忙擴充目錄；更能改善專案的 PR，會讓創作者多一個可直接拿去用的成果：

- **新 Skill**：解決明確的創作任務，附使用情境、輸入、輸出與人工檢查點。
- **實測案例**：用公開、虛構或已獲同意的素材跑過 Skill，記錄 Agent、日期、結果與限制。
- **平台適配**：同一工作流如何調整成 YouTube、Instagram、TikTok、Podcast 或電子報版本，附官方規則來源與查核日期。
- **在地化**：繁中、英文或其他語言版本，保留原始來源並說明用詞選擇。
- **可靠性改進**：減少幻覺、補來源檢查、改善時間碼／字幕處理，並附可重現例子。
- **目錄維護**：修正失效連結、過期授權或定價，提供原始證據。

從 [CONTRIBUTING.md](CONTRIBUTING.md) 開始，或查看 [貢獻任務清單](CONTRIBUTOR_TASKS.md)。

## 原創 Skill

### Audience to Content Plan

把創作者已知的受眾、內容目標與手邊素材，整理成可執行的一週計畫。Skill 會把事實、假設和需要查證的市場主張分開，避免把猜測寫成受眾研究結果。

### Topic to Short Video

從題目或來源材料產出短影音企劃。輸出包含不同角度的開場、口播草稿、分鏡提示、字幕與發布前查核項目；引用到的事實必須能回到使用者提供的來源。

### Long Video to Short Clips

從逐字稿和時間碼找出可獨立理解的片段，保留原句，不杜撰逐字稿，也不把片段剪輯建議誤稱為實際影片。沒有逐字稿或時間碼時，Skill 會明確標記限制。

## 一人媒體公司的工作流程

1. **定位與選題**：受眾、內容支柱、痛點、選題與內容日曆。
2. **腳本與文案**：開場、腳本、品牌語氣和來源查核。
3. **製作與後製**：分鏡、字幕、配音、縮圖和圖文素材。
4. **再製與發布**：核心內容轉為各平台版本，人工確認後發布。
5. **受眾與社群**：留言分類、回覆草稿、社群規範與互動回顧。
6. **營運與營收**：電子報、贊助、數位產品、分析和內容實驗。
