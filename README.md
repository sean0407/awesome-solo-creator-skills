# SoloStudio Skills

### AI 自媒體一人公司技能庫

> 一個人，也能營運一間內容公司。  *Build a one-person media company with AI.*

SoloStudio 收錄 56 個可直接閱讀的 Agent Skills，協助自媒體創作者從定位、製作到經營內容。

## 想一起改進這份清單嗎？

第一次提 PR 不必先寫程式。修一個錯字、補繁中翻譯、改清楚一個 Skill 的用途，或分享一次試用結果，都能幫到下一位創作者。

從[新手小任務](CONTRIBUTOR_TASKS.md)挑一項，改完就送 Pull Request，簡單寫下你改了什麼即可。想先確認方向？[開個 Issue 討論](https://github.com/sean0407/awesome-solo-creator-skills/issues/new/choose)。
